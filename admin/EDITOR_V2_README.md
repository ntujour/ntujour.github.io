# 📝 內容編輯器 v2 - 使用說明

## 🎉 新功能

### ✨ 富文本編輯器 (Rich Text Editor)
使用 **Quill.js** 提供專業的富文本編輯體驗：

- **文字格式化**：粗體、斜體、底線、刪除線
- **標題樣式**：H1, H2, H3 標題
- **列表**：有序列表、無序列表
- **縮排**：增加/減少縮排
- **連結**：插入超連結
- **圖片**：直接插入圖片
- **清除格式**：一鍵清除所有格式

### 🖼️ 圖片拖拽上傳
支援三種圖片上傳方式：

1. **拖拽上傳**：直接將圖片拖拽到虛線框內
2. **點擊上傳**：點擊虛線框，選擇檔案
3. **多圖上傳**：一次可上傳多張圖片

**支援格式**：JPG, PNG, GIF

**功能特色**：
- 即時預覽
- 顯示檔案名稱和大小
- 可移除已上傳的圖片（點擊 × 按鈕）
- 圖片以 Base64 格式儲存在 CSV 中

## 🚀 使用方式

### 1. 開啟編輯器

```bash
# 確保本地伺服器正在運行
python3 -m http.server 8000

# 在瀏覽器開啟
open http://localhost:8000/admin/content-editor-v2.html
```

### 2. 載入現有資料

1. 點擊「📂 載入 CSV」按鈕
2. 選擇 `data/content.csv` 檔案
3. 資料會自動載入並顯示在表格中

### 3. 新增內容

1. 填寫基本資訊：
   - 類型（新聞/活動）
   - 標題
   - 日期
   - 分類（可選）
   - 時間和地點（活動用）

2. 上傳圖片：
   - 將圖片拖拽到虛線框
   - 或點擊虛線框選擇圖片
   - 可上傳多張圖片

3. 編輯內容：
   - 使用富文本編輯器輸入內容
   - 使用工具列格式化文字
   - 可插入圖片和連結

4. 點擊「✓ 新增」儲存

### 4. 編輯現有內容

1. 在表格中找到要編輯的項目
2. 點擊「編輯」按鈕
3. 修改內容
4. 點擊「✓ 更新」儲存

### 5. 刪除內容

1. 在表格中找到要刪除的項目
2. 點擊「刪除」按鈕
3. 確認刪除

### 6. 搜尋和篩選

- **搜尋框**：輸入關鍵字搜尋標題或內容
- **類型篩選**：選擇「新聞」或「活動」進行篩選

### 7. 下載 CSV

1. 完成所有編輯後
2. 點擊「💾 下載 CSV」
3. 檔名格式：`content_2025-11-09.csv`
4. 將下載的檔案覆蓋到 `data/content.csv`

## 💡 使用技巧

### 富文本編輯器快捷鍵

|------|--------------|-----|
| 粗體 | Ctrl + B | Cmd + B |
| 斜體 | Ctrl + I | Cmd + I |
| 底線 | Ctrl + U | Cmd + U |
| 插入連結 | Ctrl + K | Cmd + K |

### 圖片處理建議

1. **圖片大小**：建議寬度不超過 1200px
2. **檔案大小**：盡量壓縮圖片，減少 CSV 檔案大小
3. **圖片格式**：優先使用 JPG（檔案較小）
4. **多圖排列**：可在富文本編輯器中插入圖片

### 內容撰寫建議

1. **標題格式**：建議使用【分類】加標題
   - 例如：【招生訊息】115學年度甄試招生簡章

2. **段落結構**：
   - 使用段落標籤（Enter 換行）
   - 使用列表整理重點
   - 適當使用標題區分段落

3. **連結插入**：
   - 選取文字
   - 點擊連結圖示
   - 輸入網址

## 🔧 技術細節

### 使用的技術

- **Quill.js v1.3.6**：富文本編輯器
- **Tailwind CSS**：樣式框架
- **Vanilla JavaScript**：無需額外框架
- **File API**：處理檔案上傳
- **Base64 編碼**：圖片儲存

### 圖片儲存格式

圖片以 Base64 格式儲存在 CSV 的 `image` 欄位：
- 單圖：`data:image/png;base64,iVBORw0KG...`
- 多圖：以 `|||` 分隔
  ```
  data:image/png;base64,ABC...|||data:image/jpg;base64,DEF...
  ```

### CSV 格式相容性

完全相容舊版 CSV 格式，只新增了 `image` 欄位的 Base64 支援。

## ⚠️ 注意事項

### 圖片大小限制

- Base64 編碼會增加約 33% 的檔案大小
- 建議單張圖片不超過 500KB
- 多張圖片可能導致 CSV 檔案過大

### 瀏覽器相容性

- Chrome/Edge：完整支援 ✅
- Firefox：完整支援 ✅
- Safari：完整支援 ✅
- IE11：不支援 ❌

### 資料備份

- 每次下載 CSV 前建議備份
- Git 會自動追蹤 CSV 變更
- 可使用 `git log data/content.csv` 查看歷史

## 🐛 疑難排解

### 問題 1：圖片拖拽沒反應

**解決方式**：
- 確保使用本地伺服器（不能直接開啟 HTML）
- 檢查瀏覽器是否支援 File API

### 問題 2：CSV 檔案過大

**原因**：Base64 圖片佔用空間大

**解決方式**：
1. 壓縮圖片後再上傳
2. 使用線上工具：TinyPNG, Squoosh
3. 或將圖片上傳到 `images/` 目錄，只在 CSV 中儲存路徑

### 問題 3：富文本內容消失

**原因**：未正確儲存

**解決方式**：
- 確保點擊「新增」或「更新」按鈕
- 不要直接重新整理頁面
- 完成編輯後立即下載 CSV

### 問題 4：格式跑掉

**原因**：HTML 標籤衝突

**解決方式**：
- 使用富文本編輯器的「清除格式」功能
- 避免從 Word 直接複製貼上（會帶入大量格式）
- 建議先貼到純文字編輯器，再貼到富文本編輯器

## 🚀 進階使用

### 圖片路徑 vs Base64

**選項 1：Base64（預設）**
- 優點：圖片直接嵌入 CSV，方便管理
- 缺點：檔案較大

**選項 2：圖片路徑**
- 優點：CSV 檔案小
- 缺點：需要管理圖片檔案
- 方法：
  1. 將圖片上傳到 `images/news/` 或 `images/activities/`
  2. 在 `image` 欄位填入相對路徑：`images/news/photo.jpg`

### 批次操作

如需批次修改大量資料：
1. 下載 CSV
2. 用 Excel 或 Google Sheets 開啟
3. 批次編輯
4. 另存為 CSV（UTF-8）
5. 重新載入到編輯器
