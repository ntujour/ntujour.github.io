# 前期所報整合說明

## 概述

已完成前期所報文件的整合工作，將 `001/Upload/366/ckfile/` 目錄中的 PDF 和 PNG 文件對應到各期所報，並使用 CSV 資料檔和 JavaScript 動態載入的方式來顯示所報列表。

## 文件結構

### 1. 資料檔案
- **位置**: `data/e-reports.csv`
- **格式**: CSV (逗號分隔值)
- **欄位**:
  - `issue`: 期數 (例如: 50, 49, 48...)
  - `title`: 標題 (例如: 第50期 所報)
  - `date`: 日期 (例如: 2024年12月)
  - `filepath`: 文件路徑 (相對於專案根目錄)

### 2. JavaScript 載入器
- **位置**: `js/e-report-loader.js`
- **功能**:
  - 從 CSV 文件讀取所報資料
  - 解析 CSV 格式
  - 動態生成 HTML 列表
  - 錯誤處理

### 3. 網頁檔案
- **位置**: `publications/e-report.html`
- **變更**:
  - 移除硬編碼的所報列表
  - 添加 `id="report-list"` 容器
  - 引入 `e-report-loader.js` 腳本

## 對應原則

文件對應採用以下原則：
1. 選擇最大的 20 個 PDF/PNG 文件（因為完整所報通常檔案較大）
2. 從最新的第50期開始往回對應
3. 最大的文件 (21MB PNG) 對應到最新的第50期
4. 依檔案大小順序對應到各期

## 工具腳本

### 1. identify-reports.py
- **功能**: 掃描 ckfile 目錄，列出所有 PDF/PNG 文件及其大小
- **用途**: 初步識別可能的所報文件

### 2. match-reports.py
- **功能**: 將文件對應到各期所報，更新 CSV 資料檔
- **用途**: 建立文件對應關係

## 使用說明

### 更新所報資料

1. 編輯 `data/e-reports.csv` 文件
2. 修改或添加所報條目
3. 保存文件
4. 重新載入 `publications/e-report.html` 頁面即可看到更新

### 添加新期所報

在 CSV 文件中添加新行：
```csv
51,第51期 所報,2025年6月,001/Upload/366/ckfile/新文件名.png
```

### 驗證文件路徑

執行以下命令驗證所有文件是否存在：
```bash
python3 match-reports.py
```

1. 20 期所報按期數從新到舊排列
2. 每期都有可點擊的鏈接

## 技術細節

### CSV 解析
JavaScript 使用簡單的 CSV 解析器，假設欄位中不包含逗號。如果未來需要支援更複雜的 CSV 格式（例如欄位中包含逗號），可以使用 Papa Parse 等第三方庫。

### 文件路徑
所有文件路徑都相對於專案根目錄，在 HTML 中使用 `../` 來正確引用。

### 錯誤處理
- 如果 CSV 文件載入失敗，顯示錯誤訊息
- 如果沒有資料，顯示「暫無資料」
- 空的 filepath 欄位會被跳過

## 已知限制

1. **文件對應準確性**: 由於無法訪問舊網站，文件對應是基於文件大小推測的。如果發現對應錯誤，需要手動調整 CSV 文件。

2. **CSV 格式限制**: 目前的 CSV 解析器不支援欄位中包含逗號或換行符號。

3. **向後兼容性**: 較舊的瀏覽器可能不支援 `fetch` API。如需支援，可以添加 polyfill。
