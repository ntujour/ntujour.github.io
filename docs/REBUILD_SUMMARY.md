# 網站重建總結

## 🎉 完成項目

### ✅ 設計與風格
- **Crimson 紅色** (#DC143C) 作為主色調，用於頁首橫幅和 H1 標題
- **灰色系** 用於內容文字，保持專業簡潔
- **最小化間距** - 避免大片空白，內容緊湊清晰
- **響應式設計** - 支援手機、平板、桌面各種裝置
- **無 jQuery** - 使用現代 Vanilla JavaScript

### ✅ 檔案結構重組

#### 新增資料夾
```
data/          →  存放所有 JSON 數據
teachers/      →  預留給教師個人頁面
articles/      →  預留給文章內容
  ├── news/    →  新聞文章
  └── activities/ → 活動資訊
```

- `index.html` - 首頁（含最新消息和活動預覽）

- `article-view.html` - 統一的文章詳細頁面

#### 數據文件
- `data/teachers.json` - 7位教師資料（可擴展）
- `data/news.json` - 6篇新聞文章（可擴展）
- `data/activities.json` - 6篇活動資訊（可擴展）

### ✅ 技術實現
- **Tailwind CSS** - 現代化 CSS 框架
- **JSON 數據驅動** - 內容與樣式分離
- **動態載入** - 使用 fetch API 載入 JSON
- **模板化系統** - 減少重複代碼

## 🚀 如何使用

### 查看網站
直接打開 `index.html` 即可，或使用本地伺服器：
```bash
cd /Users/jirlong/Library/CloudStorage/Dropbox/Programming/WWW/journalism-ntu.github.io
python3 -m http.server 8000
```
然後瀏覽 http://localhost:8000

### 修改樣式
1. 編輯 `src/input.css` 或 `tailwind.config.js`
2. 執行 `npm run build:css`
3. 重新整理瀏覽器

### 新增內容

#### 新增教師
編輯 `data/teachers.json`，新增物件：
```json
{
  "id": "newteacher",
  "name": "新老師",
  "title": "教授",
  "email": "teacher@ntu.edu.tw",
  "research": ["領域1", "領域2"],
  ...
}
```

#### 新增新聞
編輯 `data/news.json`，新增物件：
```json
{
  "id": "news001",
  "title": "新聞標題",
  "date": "2025-11-06",
  "category": "分類",
  "content": "<p>內容</p>",
  ...
}
```

#### 新增活動
編輯 `data/activities.json`，新增物件：
```json
{
  "id": "act001",
  "title": "活動名稱",
  "date": "2025-11-10",
  "time": "14:00-16:00",
  "location": "地點",
  "content": "<p>內容</p>",
  ...
}
```
